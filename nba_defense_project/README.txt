NBA DEFENSIVE ANALYSIS & PLAYER RECOMMENDATION SYSTEM

Project Overview:
This project uses MySQL to analyze NBA defensive performance
and identify players who can address defensive weaknesses of teams.

Database:
nba_defense

Base Tables:
- players
- teams
- salaries
- defensive_stats
- team_defense

Views:
- team_defensive_needs
- player_defensive_strength
- defensive_recommendations
- final_defensive_recommendations

Key Analysis:
1. Team defensive weakness identification
2. Player defensive strength scoring
3. Player-to-team matching
4. Salary-aware player recommendations
5. Final ranked defensive recommendations

The complete database structure, data, queries, and views
are included in nba_defense_project.sql.

Tools Used:
- MySQL
- SQL
